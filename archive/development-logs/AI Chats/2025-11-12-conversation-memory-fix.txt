AI Conversation Memory Implementation
Date: November 12, 2025

USER REQUEST:
"I want the AI to remember what was said when chatting with it in that current session. 
Because I asked about why is the sky blue, and then asked it what that phenomenon was 
and it didn't know what I was talking about"

PROBLEM IDENTIFIED:
The AI assistant in StudyPal was not maintaining conversation context between messages.
When user asked:
1. "ask why are the skies blue?" - AI explained Rayleigh scattering
2. "ask what is that phenomenon?" - AI didn't remember the previous conversation

The KnowledgeAssistant class was creating a new conversation with OpenAI for each 
question, without maintaining any conversation history.

SOLUTION IMPLEMENTED:
Added conversation history tracking to the KnowledgeAssistant class to maintain 
context across multiple questions in the same session.

CHANGES MADE:

1. File: FinalProject/src/studypal/agents.py
   
   a) KnowledgeAssistant.__init__():
      - Added: self.conversation_history = []
      - This list stores all messages (user questions and AI responses) during the session
   
   b) Added clear_conversation() method:
      - Allows users to reset conversation history
      - Clears self.conversation_history = []
   
   c) Modified _answer_with_ai() method:
      - Smart context loading: Only loads notes/tasks context on first question
      - Includes conversation_history in all OpenAI API calls
      - Saves both user questions and AI responses to history after each exchange
      - Implements token management: keeps only last 20 messages (10 exchanges)
      - Uses different system messages for first vs follow-up questions

2. File: FinalProject/src/studypal/cli.py
   
   a) process_command() method:
      - Added routing for "clear" command
   
   b) Added cmd_clear() method:

   c) Updated help text in cmd_help():
      - Modified "ask" description to indicate it remembers conversation
      - Added "clear conversation" command with description

HOW IT WORKS:

First Question:
- AI receives: System message with notes/tasks context + user question
- AI responds with answer
- Both question and answer saved to conversation_history

Follow-up Questions:
- AI receives: System message + full conversation_history + new question
- AI can reference previous messages to maintain context
- New exchange added to conversation_history
- History automatically trimmed to last 20 messages if it grows too large

Example Flow:
```
studypal> ask why are the skies blue?

💭 Thinking about: why are the skies blue?

🤖 AI Response:
======================================================================
The sky appears blue due to a phenomenon called Rayleigh scattering...
======================================================================

studypal> ask what is that phenomenon?

💭 Thinking about: what is that phenomenon?

🤖 AI Response:
======================================================================
Rayleigh scattering is the scattering of light by particles much 
smaller than the wavelength of light... [remembers context]
======================================================================

studypal> clear conversation
✓ Conversation history cleared. Starting fresh!
```

TECHNICAL DETAILS:

Conversation History Format:
[
  {"role": "user", "content": "why are the skies blue?"},
  {"role": "assistant", "content": "The sky appears blue due to..."},
  {"role": "user", "content": "what is that phenomenon?"},
  {"role": "assistant", "content": "Rayleigh scattering is..."}
]

Token Management:
- Keeps maximum of 20 messages (10 user-assistant exchanges)
- Prevents hitting OpenAI API token limits
- Automatically trims oldest messages when limit reached

Context Loading Optimization:
- Notes/tasks context only loaded on first question
- Saves tokens and API costs on follow-up questions
- Conversation history provides sufficient context for follow-ups

API Model:
- Uses: gpt-4o-mini
- Temperature: 0.6
- Max tokens: 500 per response

COMMANDS:

ask "your question"
- Ask questions about notes and tasks
- Maintains conversation context within session
- AI remembers previous questions and answers

clear conversation
- Resets the conversation history
- Starts fresh conversation
- Useful when changing topics
