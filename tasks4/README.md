# Tasks4 - OpenAI Task Summarizer

This package uses the OpenAI Chat Completions API to summarize task descriptions.

## Usage

```bash
uv run tasks4
```

This will process sample task descriptions and provide concise summaries using ChatGPT-4o-mini.

## Requirements

- Python 3.13+
- OpenAI API key (set as environment variable `OPENAI_API_KEY`)
- uv package manager
