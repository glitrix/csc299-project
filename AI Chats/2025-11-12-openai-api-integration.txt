## Setup Instructions Provided:

1. Install dependencies:
   ```powershell
   cd FinalProject
   pip install -r requirements.txt
   ```

2. Get OpenAI API key from https://platform.openai.com/api-keys

3. Create .env file:
   ```powershell
   Copy-Item .env.example .env
   ```

4. Add API key to .env file:
   ```
   OPENAI_API_KEY=sk-your-actual-key-here
   ```

5. Verify setup (optional):
   ```powershell
   py check_openai.py
   ```

6. Run StudyPal:
   ```powershell
   py -m src.studypal
   ```

## Technical Implementation Details:

### OpenAI Integration Pattern:
- Check if openai package is available (OPENAI_AVAILABLE flag)
- Check if API key is set in environment
- Initialize OpenAI client in StudyPlanner.__init__()
- Attempt AI-enhanced planning in try-catch blocks
- Fall back to basic planning on any errors
- Print error messages to inform user of fallback

### AI Prompt Engineering:
For plan_week:
- Sends task information (title, priority, due date, description)
- Includes available notes for context
- Requests balanced weekly schedule with specific format
- Uses gpt-3.5-turbo model with temperature 0.7

For plan_today:
- Sends candidate tasks with full details
- Requests top 5 prioritized tasks with reasoning
- Uses temperature 0.5 for more consistent results
- Extracts task IDs from response for reordering

### Backwards Compatibility:
✅ All existing functionality works without changes
✅ No migration required for data files
✅ Commands work identically with or without API key
✅ Tests pass with or without API configuration
