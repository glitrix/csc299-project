# CSC299 Project

This repository contains coursework for CSC299, including progressive tasks and the final project.

## FinalProject - StudyPal

**StudyPal** is a terminal-based study assistant that combines Personal Knowledge Management (PKMS), task management, and AI-powered features to help organize your studies.

### Key Features

- **Personal Knowledge Management System (PKMS)**: Create, organize, and search notes in Markdown format with tags and linking capabilities
- **Task Management**: Track tasks with priorities, due dates, and status tracking
- **AI Agents** (powered by OpenAI GPT-4o-mini):
  - Intelligent note summarization and semantic linking
  - AI-powered study planning and daily task recommendations
  - Quiz generation from your notes
  - Knowledge assistant with RAG-powered Q&A
  - Note content expansion and improvement
- **Local Storage**: All data stored locally in JSON format

### Getting Started

Navigate to the `FinalProject` directory and see the [README](FinalProject/README.md) for complete installation and usage instructions. Note that AI features require an OpenAI API key - see [OPENAI_SETUP.md](FinalProject/docs/OPENAI_SETUP.md) for configuration details.

### Requirements

- Python 3.11 or higher
- OpenAI API key (for AI features)
